### 🎓 [CampusAssist — Intelligent College Enquiry Chatbot](https://college-enquiry-chatbot-production.up.railway.app/)
> **Live on Railway** | Mar 2026 – Jun 2026

| | |
|---|---|
| **Stack** | Python · Flask · NLTK · scikit-learn · SQLite3 · HTML · CSS · JS |
| **Deployed** | ✅ Railway (Gunicorn WSGI) |

- 🧠 Hybrid intent classification — TF-IDF cosine similarity + exact match + keyword boosting across **25 intents & 500+ patterns**
- 🔍 Entity extraction using regex + NLP to identify dates, course names, phone numbers from free-form input
- 📅 **8-state finite state machine** for automated appointment slot booking

- 🌐 Supports **Hinglish input** for Indian student queries

### 🍽️ [DINEaus — Food Ordering & Table Reservation Platform](https://github.com/Harshitjain-11)
> Jan 2026 – Feb 2026

| | |
|---|---|
| **Stack** | Node.js · Express.js · Flask · MySQL · Socket.IO · spaCy · scikit-learn · Groq API |

- 🤖 Built **DineBot** — AI chatbot handling both food orders AND table bookings
- ⚡ **Hybrid ML + LLM architecture** — scikit-learn model (primary) + Groq API/Llama-3.1 fallback when confidence < 0.35
- 📡 **Real-time order tracking** using Socket.IO — no page refresh needed
- 🧬 spaCy + regex entity extraction — food items, quantities, dates, times, guest names
- 🗄️ MySQL relational schema — menus, users, cart, orders, and bookings
- 🔌 DineBot deployed as **independent Flask microservice** — connected via internal REST API calls
